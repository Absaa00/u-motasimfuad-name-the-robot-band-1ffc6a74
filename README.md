# The RAMones — Name the Robot Band

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/u-motasimfuad-name-the-robot-band-1ffc6a74)

Entry for the [Name the Robot Band](https://make.fun/c/u-motasimfuad-name-the-robot-band-1ffc6a74) bounty on [make.fun](https://make.fun).

Run it:

```sh
python3 main.py
```

It prints one line (under 200 characters): a funny robot band name plus a
few words about their hit song. Deterministic, no network, no randomness.
